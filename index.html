Quanah 3-Line Solver

Add the Hologram lines on each Hat, Top, Bottom, Cape, Glove and Shoe you own. The solver picks one item per slot to get as close to 18/18 as possible, filling your highest-priority lines first.

1. Add items

Click 3 lines for a . The item is added as soon as you pick the third line. Use Other for lines that don't matter. The same skill can't appear twice on one item.

Scan from game

Share your MapleStory window, then hover over each item and hold still for a moment. The page reads the tooltip from the screen share. Nothing touches the game. You can also paste (Ctrl+V) or drop a screenshot of a tooltip here.

Scanner not picking things up?
  • In the share dialog, choose the Entire screen tab and pick the monitor the game is on. This works with the game windowed or fullscreen.
  • Check "What the scanner sees" above. When a tooltip is on screen it should have a green box around it. If the picture is black, the game is blocking capture. Run the game windowed or borderless instead of exclusive fullscreen.
  • Keep the mouse still on an item for about half a second so the tooltip can settle.
  • Use Chrome or Edge. Pasting a full-screen screenshot (PrtScn, then Ctrl+V here) runs the same detection, which helps tell capture problems from detection problems.

2. Which set are you closer to?

Both sets are solved from the same items. Go with whichever one you finish first.

3. Line priorities

10 is highest, 1 is lowest. The solver fills higher-priority lines first and never gives one up to fit more lower-priority lines. Lines with the same priority count equally, so it fits as many of them as it can. Set everything equal to just maximize the total line count.
Line caps and target sets follow the Quanah World Utilities 3-Line Assistant. Your data is saved only in this browser.
